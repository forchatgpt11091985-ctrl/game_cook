# Тоскана: первая игровая сцена по утверждённому направлению

Это рабочая 3D-сцена, а не изображение концепта в качестве фона. Модели, текстуры и свет построены в Three.js. Все ресурсы формируются локально; дополнительных сетевых загрузок нет.

Сцена стала подробнее: фасады с арками и ставнями, черепица, глициния, мощение, продукты на рынке, фонтан, столики с блюдами, одежда, лицо и рюкзак героя. Камера приближена к герою; пиццерия перенесена к северо-восточной стороне площади. Координаты входа и возвращения из ресторана обновлены. Декоративные деревья и столики получили коллайдеры.

Кадр `preview/tuscany-gameplay.png` снят из игры при обычной камере. `preview/tuscany-overview.png` снят диагностической камерой с остановленным игровым временем. Это настоящие кадры рендера, без дорисовки. Утверждённый художественный концепт — отдельный ориентир; текущая процедурная сцена пока заметно проще по моделям, материалам и плотности окружения.

Автоматическая SVG-подмена удалена по требованию пользователя. Используются WebGL, ACES, текстурные материалы, тени и инстансинг. Совместимость с конкретным Mac не подтверждена; ранее сообщённая ошибка создания WebGL-контекста требует исправления настроек/поддержки браузера на этом устройстве.

Сайт не публикуется. Изменения подготовлены в отдельной ветке `art/tuscany-review`, основная версия не заменяется.

## Проверено

- TypeScript и сборка Vite проходят. Автономный HTML собран.
- Playwright/Chromium: старт, пауза, загадка Нонны, подход к Луке, частичный сбор базилика после перезагрузки, моцарелла, экзамен Марко и восстановление погони.
- Отдельный сценарий с сохранённой контрольной точки погони: 14 проверок прошли — поимка, возврат муки, проигрыш/повтор, пять гостей, рецепт, дневник, фото, карта, перезагрузка, экранная кнопка, сенсорное движение и отсутствие необработанных ошибок.
- Недоступный WebGL проверяется отдельно: понятное сообщение об ошибке, автоматического упрощения нет.
- Снимки обычной и обзорной камер получены без ошибок браузера. Замер производительности на настоящем Mac не проводился.

Для повторения: `cd app && npm run build && npm run build:standalone`; затем `npm run verify:chapter` или `FROM_CHASE=1 npm run verify:chapter` для отдельного сценария с контрольной точки. Для съёмки нужно запустить HTTP-сервер `dist` на 3020 и выполнить `node scripts/capture-art.mjs`.
