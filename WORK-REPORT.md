# Кухня Мира: восстановление и запуск

Исходники восстановлены из culinary-game-unpacked.zip. Код подготовлен для сохранения в GitHub по разрешению пользователя. Веб-сайт не публиковался.

## Что есть в игре

- Одна 3D-локация: Тоскана, Италия. Рынок, поля, фонтан и пиццерия.
- Нонна Роза: загадка и помидоры. Лука: базилик и моцарелла. Марко: три вопроса об Италии и мука.
- Критик Крюк: погоня за украденной мукой.
- Ресторан: пять последовательных действий на заказ, пять гостей, проигрыш и повтор.
- Домашний рецепт пиццы, ориентировочный бюджет, дневник готовки и чек-лист совместной работы.
- Загрузка фотографии, награда и отметка Италии на карте. Фото, дневник и прогресс хранятся в браузере.
- Монеты, звёзды и игровые фанаты. Публичного блога, настоящей социальной сети и синхронизации нет.
- Другие страны обозначены на карте, игровых глав для них пока нет.

## Исправления

- Убрана ненужная маршрутизация единственной страницы.
- Отдельная автономная сборка в один HTML: обычный script, CSS внутри, без внешних загрузок.
- Вместо пустого экрана при ошибке запуска показываются сообщение и причина.
- Пауза P/Esc теперь снимается с клавиатуры.
- Обработчик старта снимается после нажатия кнопки: последующий пробел не перезапускает главу.
- Восстановление погони после перезагрузки: мука не теряется навсегда.
- Приоритет задания погони выше подсказки повторного экзамена у Марко.
- Частично собранный базилик сохраняется.
- Убран круговой коллайдер поля, перекрывавший подход к Луке.
- Быстро обслуженный гость уходит даже до окончания анимации подхода к стойке.
- Повтор ресторана убирает прежних гостей; сброс снимает паузу и закрывает старый диалог.
- Исправлено направление поворота камеры и деление на ноль в погоне.
- Интерфейс больше не перехватывает касания пустой части экрана. Подсказка E стала кнопкой.
- Написание отчёта не вызывает игровые действия клавишами.
- Уточнены граммовки, вода, соль и действия взрослого с духовкой. Добавлены дневник и отметки реальной готовки.
- Ошибки формата/чтения фотографии сообщаются пользователю.
- При уходе со страницы сохраняется прогресс.

## Проверка и ограничения

Сборка TypeScript/Vite проходит. Chromium в Linux проверяет игру через HTTP с программным WebGL.
Проверены задания NPC, погоня, восстановление после перезагрузки, пять заказов,
проигрыш и повтор, фото, победа, карта, сохранение дневника и прогресса.
Локальный Python-сервер дополнительно проверяется скриптом verify-launch.mjs.
Для переходов между заданиями автотест использует существующий отладочный телепорт;
доступность подхода к Луке отдельно проверяется обычным движением клавишей W.

Управляемый Chromium запрещает file:// политикой среды. Поэтому открытие HTML
двойным щелчком здесь НЕ подтверждено; рекомендуемый путь — локальный HTTP-сервер.
Windows недоступна: launcher PowerShell подготовлен, но на Windows не исполнен.
Публикация и внешний адрес не создавались.

## Повторяемые команды

В app:
- npm ci --cache /tmp/game-cook-npm
- npm run build
- npm run build:standalone
- npm run verify:chapter
- python3 release/server.py
- node scripts/verify-launch.mjs (при работающем сервере)

Скачать/передать пользователю нужно release/index.html и файлы запуска из release.
Папка node_modules для готовой игры не нужна.

## Совместимость с Mac без WebGL

Добавлен программный SVG-рендерер того же 3D-мира: автоматическое переключение при ошибке создания WebGL-контекста. Упрощены модели, отключены тени и текстурные спрайты. Игровая логика и сенсорный canvas остаются прежними. Проверка проводится с принудительно отключённым WebGL через NO_WEBGL=1 npm run verify:chapter.

Проверка программного режима: движение, NPC, частичный сбор, перезагрузка во время погони, ресторан, проигрыш/повтор, фото, дневник, карта, сохранения и сенсорное управление. Обычный WebGL-режим дополнительно проходит smoke-проверку рендера и управления.
