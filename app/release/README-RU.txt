КУХНЯ МИРА — ИТАЛИЯ

Windows:
1. Распакуй весь ZIP через «Извлечь всё». Не запускай файлы внутри архива.
2. Дважды нажми START-WINDOWS.cmd. Используется встроенный PowerShell; Node.js и Python не нужны.
3. Браузер откроет http://127.0.0.1:8765/ на ТВОЁМ компьютере.
4. Оставь окно запуска открытым. Закрой его, когда закончишь играть.
Если окно уже открыто, повторно запускать сервер не надо — открой адрес выше.

macOS / Linux с установленным Python 3:
Открой «Терминал», введи /bin/sh и пробел, перетащи START-MAC-LINUX.command в окно терминала и нажми Enter.
Либо перейди в распакованную папку и выполни: python3 server.py
Если python3 не найден, установи Python 3 с https://www.python.org/downloads/macos/ и повтори запуск.

Альтернативный вариант: открой index.html в Chrome или Edge.
Открытие файла с диска в управляемом браузере нашей среды запрещено политикой,
поэтому для проверенного способа используй локальный сервер.
Если игра не запускается, она покажет текст ошибки — пришли его.
Для 3D требуется WebGL 2 и включённое графическое ускорение браузера.

Управление:
WASD / стрелки — движение. Зажми кнопку мыши и двигай мышь — камера.
E или кнопка подсказки на экране — разговор / действие.
P или Esc — пауза и продолжение.
На сенсорном экране: левая половина — движение, правая — камера.

Путь главы:
Нонна Роза → фермер Лука → 3 листика базилика → Лука → шеф Марко →
Критик Крюк → жёлтый круг у двери пиццерии → 5 гостей → рецепт → фото → карта.
Реальное блюдо готовь со взрослым. Нож, горячий противень и духовка — с его помощью.

Сохранение:
Прогресс и фото остаются только в этом браузере по этому адресу.
Очистка данных браузера, другой профиль или устройство не сохраняют этот прогресс.
Интернет, регистрация и отправка фото на сервер не требуются.
Фанаты и монеты — внутриигровые; публичного блога нет.
Реализована Италия. Другие страны на карте — пока отметки будущих глав.
